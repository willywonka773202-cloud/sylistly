# Deploy Sylistly To `sylistly.com`

This repo is set up for a direct Vercel deployment.

## Recommended path

1. Push the latest `main` branch to GitHub.
2. In Vercel, import the GitHub repo: `willywonka773202-cloud/sylistly`.
3. Set the production environment variables from `.env.local` and `.env.example`.
4. Set:

```env
NEXT_PUBLIC_APP_URL=https://sylistly.com
SEARCH_MODE=catalog-only
```

5. Deploy.
6. In the Vercel project:
   - go to `Settings -> Domains`
   - add `sylistly.com`
   - add `www.sylistly.com`
7. In your domain registrar DNS:
   - set the apex/root `@` record to Vercel as instructed in the Vercel UI
   - set `www` to the Vercel CNAME target shown in the Vercel UI
8. In Vercel, make `sylistly.com` the primary domain and redirect `www` to apex.

## Why this repo is ready now

- proper canonical metadata points to `https://sylistly.com`
- `robots.txt`, `sitemap.xml`, and web manifest are generated by Next.js
- favicon, Apple icon, and Open Graph image are included
- `vercel.json` is present for a clean Next.js deployment

## Production recommendation

For the first public launch, keep the app in local-catalog mode:

```env
SEARCH_MODE=catalog-only
```

That avoids runtime paid search dependency while you keep improving the inventory.
